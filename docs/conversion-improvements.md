# 浏览器转换改进记录

范围：保持离线、GitHub Pages、公开转换函数返回 Blob。参考 VERT 的引擎接口/取消任务思想、PPTist 的打印导出、pdf2docx 的区域分析、docxjs 的页面渲染；不复制 AGPL 实现。

任务与验收：

- [x] 真实 BMP/ICO/MP3/OGG 编码、中文 TXT PDF；验证文件头和内容。
- [x] PDF 先分区再合行；保留正文中的重复页眉文字、运行间空格及图片。
- [x] PPT 截图兼容、图形回归、主渲染失败明确降级、PNG 多页、可选打印。
- [x] Word 增加本地 docx-preview 版式路径，保留简洁正文路径，校验分页/纸张/表格/图片。
- [x] 转换注册表、任务取消/进度/失败重试、工作线程编码及资源回收。
- [x] 自生成有效样本、最终文件视觉和结构测试、完整回归和独立审查。

决定：在现有 codex/conversion-stability 分支修改，保留未提交改动和被删除的旧二进制样本。测试样本生成到临时目录。浏览器 DOM 渲染仍在主线程，编码和像素处理用 Worker；file:// 不允许外部 Worker 时使用同一编码算法并定期让出事件循环。

初始证据：开始前已复现 BMP/ICO 实际 PNG、MP3 实际 WebM、中文 TXT 字体缺失、双栏合并、页眉删除正文。当时 PPT 渐变兼容函数尚未接入正式截图。

验证记录：上述五个回归最初全部失败，修复后通过。PPT 图形/渐变数字、多页 PNG、手机视口滚动后重复导出已验证；Word 横版两页、图片/表格/分页已验证；静态 HTTP 页面真实执行 MP3/OGG/GIF/WebM，文件头正确且转码临时文件清空。首次完整 test:all 通过，PPT 压测 25/25/40 页输出一致，零外部请求。

独立审查：发现 Word 克隆丢失 iframe 样式、PPT 打印图片 URL 提前释放、紧密双栏误当表格、PDF 版式 HTML 取消延迟四个问题。全部先用 verify-review-fixes.mjs 复现为失败，再修复为通过；Word 显式复制计算样式及字体/编号样式，打印资源延迟到 afterprint 回收，表格识别改用独立网格线证据，逐页渲染增加取消检查。

Ruling: 表格候选采用网格线证据，而不是仅凭行距推断 — 行距无法区分紧密双栏与表格；代价是无边框表格可能按分栏文本输出，需要版式优先模式保留外观。

Ruling: 自动 Word/PPT PDF 保持页面图路径以兼容 Blob 返回，PPT 另有系统打印入口 — 浏览器打印不会直接返回 Blob；代价是自动导出 PDF 文字不可搜索，Word 自动分页仍不是 Office 引擎。

Ruling: 视频/OGG 使用匹配的 @ffmpeg/ffmpeg 0.12.15 + @ffmpeg/core 0.12.10 单线程版本 — 无需 GitHub Pages 不支持自定义的跨源隔离响应头；代价是转码比原生程序慢，file:// 无法读取 WASM 时明确提示使用静态 HTTP(S) 页面。
