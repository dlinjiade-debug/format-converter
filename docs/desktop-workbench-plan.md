# 双端转换工作台

范围：继续保留浏览器转换核心；提供 Windows 便携软件与公开网站。桌面端用原生目录选择保存输入/输出/参考路径；网页端使用浏览器授权目录或普通下载，不假称能读取任意磁盘路径。

- [x] 输入预检：页数、缺失字体、媒体和兼容性、受控 ZIP 元数据扫描。
- [x] 输出预览：逐页检查后手动下载；取消/换文件释放资源。
- [x] 字体和 PDF：加载本地 TTF、保留外观的可搜索文字层、SVG 真矢量导出；缺少中文字体时显示图片降级警告。
- [x] 大文件：像素预算、自适应分辨率、逐页释放和进度。
- [x] 真实文件验收工具：可配置源/独立参考 PDF，记录哈希和逐页图像/文字指标。
- [ ] 用户真实文件最终视觉验收：原来提供的两条 E: PDF 路径目前不存在，不能标为通过。
- [x] Windows 核心：路径设置持久化、受限原生文件桥、开发版及 app.asar 完整转换保存流程通过。
- [x] 最终便携 EXE：重建后实际启动验收通过，准备发布。
- [ ] 网站：共享转换界面、公开访问、静态资源发布，不上传用户文件。
- [x] 测试：桌面路径边界、浏览器流程、搜索文字、图像质量、全套回归、独立审查及其三项缺陷回归。

已有 codex/conversion-stability 工作区中的前轮修复全部保留；不恢复用户删除的旧 PPTX 样本。真实文件样本与验收输出不提交到 GitHub。
